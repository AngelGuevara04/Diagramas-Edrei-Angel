Recortador SVG a PDF

Marca regiones rectangulares sobre un SVG grande y expórtalas como páginas. Tienes que convertir el el archivo drawio en PDF y luego en SVG.

1. Cargar SVG

Selecciona un archivo SVG vectorial.

Si tu archivo original es PDF, conviértelo primero a SVG (por ejemplo con Inkscape, Ghostscript, etc.).

2. Dibujar recortes

Haz clic y arrastra sobre el área del SVG para crear un rectángulo de recorte.

Cada recorte será una hoja del PDF resultante. Con Ctrl mantenido puedes mover o redimensionar un recorte existente, y mientras esté presionado no se crearán recortes nuevos.

3. Exportar

Exporta todos los recortes como:

1 = tamaño justo de página. Usa 2-3 para más nitidez (archivos más pesados).

SVG mantiene la calidad vectorial. El PDF también será vectorial si el contenido original lo era.

Recortes (Hojas)

Haz clic en una hoja para resaltarla. Puedes reordenar o eliminar.
