Comandos

  • S → siguiente imagen.
  • D → borra el archivo y pasa a la siguiente.
  • X → recorta el 10% inferior, guarda y pasa a la siguiente (muestra 0.5 s).
  • Click + arrastrar → dibuja un rectángulo libre para recortar esa región, guarda y pasa a la siguiente (muestra 0.5 s).
  • M (mientras arrastras) → cancela el recorte actual.
  • ← (flecha izquierda) → regresar a la imagen anterior (saltando las borradas).
  • Z → deshacer la última acción (borrado o recorte) sobre el archivo real.

⚠ Esta versión SÍ modifica los archivos en disco (borrados y recortes).

Necesitas Chrome o Edge y abrir este archivo desde http://localhost (por ejemplo con python -m http.server) para que el navegador permita el acceso al sistema de archivos.
